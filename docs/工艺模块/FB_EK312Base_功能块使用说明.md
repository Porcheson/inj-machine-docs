# 《FB_EK312Base 功能块使用说明》

| 项目     | 内容                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 模块名称 | `FB_EK312Base`                                                                              |
| 适用场景 | 注塑机 EK312 温控模块 12 路温区参数下发、实际温度采集、温区状态判断、温控板配置和通信变化监视 |
| 版本信息 | 文档版本 1.1；库版本 1.0.0；ABI 1；更新日期 2026-08-11                                        |
| 事实原则 | 以下描述以当前 ST 执行逻辑为准；地址单位和编码无法由源码确认时标注“需协议确认”              |

## 1. 功能概述

`FB_EK312Base` 为 EK312 温控模块提供统一的数据接口。调用者写入 12 路温控设定、射咀参数和板型相关配置，功能块将这些数据组织到 `aOutputAddr[0..99]`；调用者提供模块输入地址数据，功能块输出实际温度、温区状态、加热状态、版本号和通信报警。

### 输入与输出

| 输入                                                  | 输出                                    |
| ----------------------------------------------------- | --------------------------------------- |
| 温控板型号、温控使能、保温使能、报警复位、R0..R3 使能 | 模块报警与报警代码                      |
| 12 路温控设定与模块配置                               | 输出地址缓冲`aOutputAddr[0..99]`      |
| 模块输入地址`aInputAddr[0..49]`                     | 12 路实际温度、温区状态、热状态和版本号 |

### 主要流程

```text
循环调用
  -> 清零输出地址缓冲
  -> 根据保温使能选择温度设定值或保温设定值
  -> 写入 12 路温控参数和固定模块配置
  -> 复制实际温度、热状态和版本号
  -> 计算每路温区状态
  -> 监视输入地址 30 的变化并生成通信报警
  -> 报警复位优先清除报警输出
```

本功能块不实现 PID 闭环、通信报文收发、物理 I/O 访问、加热电源切断。

## 4. ST 内部逻辑

### 4.1 输出地址与参数映射

每次调用先将 `aOutputAddr[0..99]` 全部写 0，再按下表重新写入。因此未列出的地址在本周期为 0，调用方不得依赖上周期值。

|  地址/下标 | 数据来源                                | 对外含义       | 条件或范围                  |
| ---------: | --------------------------------------- | -------------- | --------------------------- |
|  `0..11` | `aSeg[0..11].uiSetTemp`               | 12 路温度设定  | 每次调用                    |
|     `16` | `BOOL_TO_UINT(bTempEnable)`           | 温控使能       | 每次调用                    |
|     `17` | `uiANozMode`                          | A 色射咀方式   | 每次调用                    |
|     `22` | `uiANozPerc`                          | A 色射咀百分比 | 每次调用                    |
|     `24` | `uiContSSR`                           | SSR 选择       | 每次调用                    |
|     `25` | 按`uiBoardModel` 及 `bR0..bR3` 计算 | 输出点配置字   | `uiBoardModel=0` 或 `1` |
|     `26` | `uiNozCtrlCycle`                      | 射咀控制周期   | 每次调用                    |
| `32..43` | `aSeg[0..11].uiFunc`                  | 12 路温区功能  | 每次调用                    |
| `48..59` | `aSeg[0..11].uiP`                     | 12 路 P 参数   | 每次调用                    |
| `64..75` | `aSeg[0..11].uiD`                     | 12 路 D 参数   | 每次调用                    |
|     `80` | 固定 0                                  | 色数选择       | 固定写入                    |
|     `81` | 固定 255                                | A 色选择       | 固定写入                    |
|     `82` | 固定 255                                | B 色选择       | 固定写入                    |
|     `83` | 固定 255                                | C 色选择       | 固定写入                    |
|     `84` | 固定 0                                  | B 色射咀方式   | 固定写入                    |
|     `85` | 固定 0                                  | B 色射咀百分比 | 固定写入                    |
|     `86` | 固定 0                                  | C 色射咀方式   | 固定写入                    |
|     `87` | 固定 0                                  | C 色射咀百分比 | 固定写入                    |

输出地址 25 的配置按板型选择：`uiBoardModel=0` 表示 EK312T_R 继电器型号，输出配置字为 0；`uiBoardModel=1` 表示 EK312T_T 晶体管型号，配置字的基值为 `16#00F0`，`bR0`、`bR1`、`bR2`、`bR3` 分别附加 `16#1000`、`16#2000`、`16#4000`、`16#8000` 配置位。因此 `bR0..bR3` 仅适用于 EK312T_T 晶体管型号。该字是模块协议数据，不是功能块直接驱动继电器。`uiBoardModel` 取值仅对 0 和 1 有源码分支，其他取值未实现，调用方应按协议限定。

保温设定分支仅影响输出地址 `0..11`：`bKeepWarm=FALSE` 时使用 `aSeg[0..11].uiSetTemp`，`bKeepWarm=TRUE` 时改用 `aSeg[0..11].uiKeepTemp`；温区功能、P 参数和 D 参数的地址映射不变。

### 4.2 输入数据和温区状态

| 数据项        | 来源                            | 当前处理                               |
| ------------- | ------------------------------- | -------------------------------------- |
| 12 路实际温度 | `aInputAddr[0..11]`           | 原值复制到`aSeg[0..11].uiActualTemp` |
| 加热状态      | `aInputAddr[20]`              | 保留低 12 位后写入`uiHeatState`      |
| 版本号        | `aInputAddr[22]`              | 原值复制到`uiVersion`                |
| 温区状态      | 实际温度和对应`ST_EK312InSeg` | 计算后写入`uiState`                  |

每路温区状态按以下顺序覆盖：先置 0；实际温度低于“设定值减下偏差”置 1；高于“设定值加上偏差”置 2；实际温度为 0 或大于 9990 置 3；最后 `uiFunc=0` 时强制回到 0。状态判断没有滤波、比例换算、限幅或单位转换。

### 4.3 通信变化监视和复位

功能块比较 `GetTime3` 经 `TIME_TO_UINT` 转换后的值；当其达到 `30000` 时，比较 `aInputAddr[30]` 与上次采样值。若两次采样相同，则置通信报警位 `16#0001`，随后刷新采样和计时基准。该阈值的时间单位以运行时 `TIME` 定义为准，不应再按调用次数换算。

`bAlarmReset` 位于执行末尾：同一调用中即使通信报警条件成立，`bAlarmReset=TRUE` 仍会使最终 `bAlarm=FALSE`、`dwAlarmID=0`。复位不改变输出地址缓冲、实际温度、温区状态或通信变化监视的历史状态；输入地址持续不变时，释放复位后可再次报警。

## 5. 报警和状态码

### 5.1 报警代码与报警信息

| 报警代码            | 报警信息         |
| ------------------- | ---------------- |
| `16#0000`         | 无报警           |
| `16#0001`（bit0） | 温度模块通讯失败 |

通信报警在 `TIME_TO_UINT(GetTime3) >= 30000` 且 `aInputAddr[30]` 与前一次采样相同时按位 OR 到 `dwAlarmID`，并保持到 `bAlarmReset=TRUE`。当前 ST 只会写入 bit0；温区偏低、偏高和断线状态不会自动转换为 `dwAlarmID`。

### 5.2 温区状态码

| `uiState` | 含义             |
| ----------: | ---------------- |
|           0 | 正常或温区未启用 |
|           1 | 偏低             |
|           2 | 偏高             |
|           3 | 断线             |

`uiState` 是每路温区结果，不是功能块报警代码。温区未启用时，最终状态始终为 0。

## 6. 调用规范和注意事项

1. 在固定周期内调用一次。通信监视使用 `TIME_TO_UINT(GetTime3) >= 30000` 时间阈值，具体时间单位需结合运行时 `TIME` 定义确认，不按调用次数换算。
2. 调用前先刷新 `aInputAddr[0..49]`，调用后再读取/下发 `aOutputAddr[0..99]`，避免读写跨周期混用。
3. `uiBoardModel` 应按协议设置为 0（EK312T_R 继电器）或 1（EK312T_T 晶体管）；`bR0..bR3` 仅在取值 1 时参与输出地址 25。
4. `aOutputAddr[0..99]` 每次重建，调用方不能在数组中混写需要保留的其他协议字。
5. `bTempEnable=FALSE` 仅使输出地址 16 为 0；其他温控参数和模块配置仍会按当前输入写入。
6. `bAlarmReset` 是电平复位，只清报警输出和报警码；不会重启通信监视。输入地址 30 持续不变时，复位释放后会再次报警。
7. `uiSetTemp-uiMin` 和 `uiSetTemp+uiMax` 使用 `UINT` 运算。调用方应保证范围合理，避免下溢或上溢造成状态误判。
8. 温度、射咀百分比、射咀控制周期、热状态和协议字单位均需协议确认。
9. 功能块只组织通信缓冲和诊断结果，不替代温控安全保护或物理加热切断。
10. `bKeepWarm=TRUE` 时应先为 12 路 `uiKeepTemp` 提供有效值；关闭保温后，输出地址 `0..11` 恢复使用 `uiSetTemp`。

## 7. 外部交互边界

| 方向 | 交互对象         | 数据边界                                                               |
| ---- | ---------------- | ---------------------------------------------------------------------- |
| 输入 | HMI/配方         | `uiBoardModel`、`aSeg`、射咀参数、SSR 选择、温控使能和 R0..R3 使能 |
| 输入 | EK312 通信读逻辑 | `aInputAddr[0..49]`                                                  |
| 输出 | EK312 通信写逻辑 | `aOutputAddr[0..99]`                                                 |
| 输出 | HMI/诊断/报警    | 实际温度、温区状态、热状态、版本号和报警                               |

当前 ST 不调用其他功能块，不直接访问 `%I/%Q`，不创建通信报文。通信读写、协议转换和加热执行均在本功能块外部完成。

`bKeepWarm` 由外部配方或保温控制逻辑提供；功能块只根据该信号选择输出地址 `0..11` 的设定值，不执行保温状态机或温度闭环控制。

## 8. 最小调用示例

本功能块没有轴控制接口。最小调用链为“刷新模块输入地址 -> 调用功能块 -> 下发模块输出地址”，不应附加液压轴或电动轴调用。

```ST
(* 外部通信读逻辑先刷新 stInPara.aInputAddr[]。 *)
fbExample(
  uiBoardModel := uiBoardModel,
  bTempEnable := bTempEnable,
  bKeepWarm := bKeepWarm,
  bAlarmReset := bAlarmReset,
  bR0 := bR0,
  bR1 := bR1,
  bR2 := bR2,
  bR3 := bR3,
  stInPara := stInPara,
  bAlarm => bAlarm,
  dwAlarmID => dwAlarmID,
  stOutPara => stOutPara
);

(* 外部通信写逻辑读取 stOutPara.aOutputAddr[]；
   HMI/诊断读取 stOutPara.aSeg[]、uiHeatState、uiVersion 和报警输出。 *)
```
